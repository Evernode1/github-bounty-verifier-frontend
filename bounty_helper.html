GitHub Bounty Verifier

Helper tools for contributors and creators (GenLayer, paid in GEN).

How it works

  1. Creator escrows a GEN reward for a repo.
  2. Contributor adds their wallet line to the PR description.
  3. After merge, contributor submits the PR link with a small GEN deposit.
  4. Validators read GitHub and an LLM checks the requirements.
  5. If approved, the PR is locked forever and the winner claims the payout.
